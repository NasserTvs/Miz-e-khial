# میز خیال | Miz-e-khial

**[🎴 ورود به بازی آنلاین](https://stozhit-mah-khial.leapingknack64.chatgpt.site/game)**

بازی فارسی قصه و تصویر برای ۲ تا ۸ نفر، با ۸۰ کارت مصور. هر بازیکن روی گوشی یا کامپیوتر خودش بازی می‌کند و دست خصوصی خودش را می‌بیند.

برای شروع، یک نفر «ساخت میز جدید» را بزند و لینک دعوت یا کد شش‌رقمی میز را برای دوستانش بفرستد. بعد از ورود همه، میزبان «شروع بازی» را می‌زند. ذره‌بین گوشهٔ کارت تصویر را بزرگ می‌کند و صدای مراحل از بالای صفحه قابل تنظیم است.

## اجرای نسخهٔ مخزن روی کامپیوتر

با Node.js نسخهٔ ۲۲ به بالا، در پوشهٔ پروژه دستورهای زیر را اجرا کنید. فرمان دوم پایگاه دادهٔ محلی را آماده می‌کند و آدرس بازی را در ترمینال نشان می‌دهد.

```sh
npm install
npm run dev
```

تصویرها، فونت‌ها و رابط بازی در پوشهٔ `public` و قوانین بازی و سرویس میزها در پوشهٔ `src` قرار دارند. لینک بالای صفحه به نسخهٔ آنلاین متصل است. برای میزبانی مستقل با Cloudflare Workers، یک پایگاه D1 ایجاد کنید، شناسهٔ آن را جایگزین شناسهٔ نمونه در `wrangler.jsonc` کنید، سپس مهاجرت و انتشار را اجرا کنید.

```sh
npx wrangler d1 migrations apply DB --remote
npx wrangler deploy
```
